# Wise Way Round

Landing page for Wise Way Round — Zoe & Mark's travel blog/vlog. Treading the globe, seeking adventure, exploring culture, and finding words of wisdom along the way.

## Running locally

No build step needed — it's plain HTML/CSS/JS. Either:

- Open `index.html` directly in your browser, or
- Serve it locally with `npx serve .`

## Deployment

This site deploys to [Vercel](https://vercel.com) directly from this GitHub repository as a static site, with no build configuration required.
